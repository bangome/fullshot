# FullShot 📸 — 풀페이지 스크린샷 크롬 확장

스크롤을 내려야 보이는 영역까지 포함해 웹페이지 **전체를 한 장의 이미지**로 캡처하는 Chrome 확장 프로그램입니다. 외부 라이브러리·빌드 도구 없이 순수 정적 파일(Manifest V3)로만 구성되어 있어 그대로 로드해 사용할 수 있습니다.

## 주요 기능

- **전체 페이지 캡처** — 화면을 단계적으로 스크롤하며 캡처한 뒤 canvas 로 이어붙임
- **보이는 화면 캡처** — 현재 뷰포트만
- **영역 선택 캡처** — 마우스로 드래그한 사각형 영역만
- **출력 형식** — PNG · JPEG(품질 조절) · PDF · 클립보드 복사
- **미리보기/편집 페이지** — 캡처 후 새 탭에서 미리보기, 크롭, 형식 선택 후 저장
- 고정(fixed/sticky) 헤더 중복 방지, 지연 로딩(lazy-load) 콘텐츠 프리로드, 고해상도(DPR) 대응

## 설치 (개발자 모드)

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`fullshot/`)를 선택

툴바에 📸 아이콘이 추가됩니다.

## 사용법

1. 캡처할 페이지에서 📸 아이콘 클릭
2. **전체 페이지 / 보이는 화면 / 영역 선택** 중 선택
   - 영역 선택은 페이지 위에서 드래그(ESC 로 취소)
3. 캡처가 끝나면 **편집 탭**이 새로 열림
4. 필요하면 ✂️ 크롭으로 영역 잘라내기
5. 형식(PNG/JPEG/PDF) 선택 후 **⬇️ 저장** 또는 **📋 복사**

### 설정 (팝업 → ⚙️ 설정)

- **기본 형식** / **JPEG 품질** / **스크롤 지연(ms)** — `chrome.storage.sync` 에 저장
- 스크롤 지연은 지연 로딩이 많은 페이지에서 값을 키우면 빈 영역을 줄일 수 있음

## 동작 방식

```
popup → background(service worker) → content script(대상 페이지)
                  │                         │  스크롤하며 위치마다 캡처 요청
                  │  captureVisibleTab      │
                  │  (초당 2회 제한 throttle)│
                  ▼                         │
            타일 수집 → storage.local 저장 → editor 탭 오픈
                                                  │ stitch(타일 합성)
                                                  ▼  크롭/형식변환/저장
```

- 캡처는 `chrome.tabs.captureVisibleTab` 으로 viewport 를 여러 장 찍어 합성합니다(디버거 API 미사용 → 경고 배너 없음).
- PDF 는 외부 라이브러리 없이 JPEG 를 PDF 에 임베드하는 자체 생성기(`src/lib/pdf.js`)로 만듭니다.

## 파일 구조

```
fullshot/
├─ manifest.json
├─ src/
│  ├─ background.js        # 오케스트레이션 + captureVisibleTab throttle
│  ├─ content.js           # 페이지 측정·스크롤·고정요소 처리·영역선택
│  ├─ content.css
│  ├─ popup/               # 버튼 UI + 설정
│  ├─ editor/              # 미리보기·크롭·저장 페이지
│  └─ lib/
│     ├─ stitcher.js       # 타일 합성/크롭
│     └─ pdf.js            # 의존성 없는 JPEG→PDF 생성기
├─ icons/                  # 16/32/48/128 png
└─ README.md
```

## 알려진 한계

- 브라우저 canvas 최대 크기(보수적으로 16384px)를 넘는 매우 긴 페이지는 잘릴 수 있습니다(경고 표시). 이 경우 영역을 나눠 캡처하세요.
- `chrome://`, Chrome 웹스토어 등 내부 페이지는 캡처할 수 없습니다.
- iframe 내부의 별도 스크롤 콘텐츠는 완전히 캡처되지 않을 수 있습니다.
- 캡처 중에는 페이지가 자동 스크롤되므로 잠시 조작하지 마세요.
